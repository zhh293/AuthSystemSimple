# Design: Authentication Metrics

`SsoMetrics` wraps Micrometer counters with bounded labels. `IdentityServiceProvider` records login and TGC validation outcomes; `TokenIntrospectionServiceProvider` records active/inactive results and separately counts unexpected storage/dependency failures. The HTTP logout controller increments the request counter before RPC so failed discovery/transport attempts are included, and increments a separate dependency-failure counter if server-side revocation cannot be confirmed. `DirectoryAccountSyncConsumer` records page, failure, and conflict outcomes. `FamilyAwareRefreshTokenGenerator` records refresh-family creation, successful rotation, stale/replayed tokens, and other rejected rotations. No event includes identity or credential values.

The Prometheus registry is supplied by Micrometer. Spring Boot Actuator runs on the dedicated management port (`SSO_MANAGEMENT_PORT`, default `8081`) and binds to loopback (`SSO_MANAGEMENT_ADDRESS`, default `127.0.0.1`). Operators who change the bind address must restrict the management port to a private monitoring network; the scrape endpoint does not use application-level authentication. `ops/monitoring` supplies Prometheus scrape/alert templates and a Grafana dashboard. Operators must set the scrape target, enable Prometheus environment expansion, restrict network access, and tune starter alert thresholds to their SLOs. Backup recovery drills and security review remain operational rollout work.
